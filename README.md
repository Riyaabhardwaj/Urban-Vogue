
🛍️ Urban Vogue – Online Clothing Store
Urban Vogue is a full-stack e-commerce web application that allows users to browse, search, and purchase clothing items seamlessly. Built using the MERN stack, it delivers a modern, responsive, and user-friendly shopping experience.

✨ Features
User Authentication

Sign up, log in, and manage user profiles securely

Product Catalog

Browse a wide range of clothing items with images, descriptions, and pricing

Search & Filters

Quickly find products using category-based filters and search functionality

Shopping Cart

Add, remove, and update items before checkout

Secure Checkout

Integrated payment gateways (Stripe / PayPal) for safe transactions

Order Management

View and track current and past orders

Admin Dashboard

Manage products, users, and orders efficiently

🛠️ Tech Stack
Frontend
React.js

Redux

Tailwind CSS

Backend
Node.js

Express.js

Database
